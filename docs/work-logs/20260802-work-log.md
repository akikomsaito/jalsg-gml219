## 照合で判明した齟齬

### 地固め療法の Grade 3 以上有害事象の分母

抄録の 86.8% / 25.6% / 22.3% / 23.1% は、当方提出の `Inquiry04 (4-3)` の値（105/121、31/121、27/121、28/121）と完全一致しており、**4つとも分母がFAS 121例**であることが確定した。地固めの実施例は 51 / 44 / 40 例であり、実施例を分母にすると 60.8% / 61.4% / 70.0% になる。現在の文面は地固め療法の安全性を大幅に過小評価する。あわせて、この数値はCRF収集33項目のうち**主要10項目に限定**した集計であり、"Grade ≥3 AE" という表記は全有害事象と誤読される。

### 寛解導入療法のダウノルビシン用量

抄録は「45 mg/m²/day」のみ記載しているが、PRT ver2.4 は **65-69歳 45 mg/m²、70-74歳 35 mg/m²** の年齢層別規定。FASは70-74歳が73例（60.3%）と過半数で、実測のDNR総投与量中央値 105 mg/m²（=35×3）、平均 116.8（年齢構成からの理論値 116.9）がこれを裏付ける。年齢層別用量は本試験の設計思想であり、タイトルの "fitness-adapted" とも直結するため記載漏れは致命的。

### 30日死亡率

抄録は 1.65%（2/121）。当方データでは寛解導入1開始日から30日以内の死亡は **1例（0.8%）**（登録日起算でも1例）。1.65%に一致するのは35日以内（32日目の死亡1例が加わる）。起算日と期間の定義確認が必要。

## 30日死亡率の出所

伊藤先生の「1.65%」がどこから来たかを調査し、**当方の計算ミスではない**ことを確認した。

- Table1〜8・Fig1〜10・Inquiry01〜04 のいずれにも30日死亡率・早期死亡率の集計はなく、SAPにも規定がない。当方は算出・提供していない。
- 2例（1.65%）は、6月26日の照会対応で説明した「効果判定が未評価のまま死亡した2例」と完全一致した。GML219-0066（導入開始2021-08-04→死亡2021-08-10、6日目）とGML219-0108（導入開始2022-09-15→死亡2022-10-17、32日目）。両例とも導入2コース目・地固めに進んでいない。
- したがって2例は「寛解導入療法の効果判定前の死亡」としては正確で、"30-day" という期間指定と合っていないだけ。当方集計では30日以内1例（0.8%）、35日以内2例（1.65%）、60日以内3例（2.5%）。
- メール案では "Two patients (1.65%) died during induction therapy before response assessment." への変更を提案する形に落ち着いた。
